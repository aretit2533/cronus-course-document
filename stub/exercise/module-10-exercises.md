# Module 10 Exercises: Advanced Enterprise Patterns

## Exercise 10.1: DDD Boundaries

**Goal:** Define an aggregate boundary.

**Tasks**

1. Choose a domain (e.g., Orders).
2. Define entity/value objects.
3. Define aggregate invariants.

**Deliverable**

- A short DDD model description.

---

## Exercise 10.2: Event Design

**Goal:** Design an event-driven flow.

**Tasks**

1. Define 3 domain events.
2. Define idempotency strategy for consumers.

**Deliverable**

- Event definitions + idempotency notes.

---

## Exercise 10.3: Resilience Review

**Goal:** Apply resilience patterns to a dependency.

**Tasks**

1. Pick a dependency call.
2. Define timeout, retry, circuit breaker rules.
3. Define fallback behavior.

**Deliverable**

- Resilience policy + operational metrics.
