# Module 5 Exercises: Data Processing and Pipes

## Exercise 5.1: Joi Schema Validation

**Goal:** Create a Joi schema for a DTO.

**Tasks**

1. Design a DTO with nested fields (at least 2 levels deep).
2. Write Joi validation rules including custom messages.
3. Define what should happen on validation failure.

**Deliverable**

- DTO + Joi schema + sample validation error response.

---

## Exercise 5.2: Transformation Pipeline

**Goal:** Define a multi-stage transformation pipeline.

**Tasks**

1. Define 3 stages: normalize, validate, transform.
2. Define the input and output for each stage.

**Deliverable**

- Pipeline spec + example input/output.

---

## Exercise 5.3: Batch Processing Strategy

**Goal:** Design batch processing with retry.

**Tasks**

1. Choose batch size and concurrency.
2. Define retry policy and what is considered retriable.

**Deliverable**

- Batch config + retry logic description.
