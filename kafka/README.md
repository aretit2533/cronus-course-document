## 🎯 Course Overview

Apache Kafka is a distributed event streaming platform used by thousands of companies for high-performance data pipelines, streaming analytics, data integration, and mission-critical applications. This course covers everything you need to become proficient with Kafka.

## 👥 Target Audience

- Backend Developers
- Data Engineers
- Software Architects
- DevOps Engineers
- Anyone interested in event-driven architectures and real-time data processing

## 📋 Prerequisites

- Basic understanding of distributed systems
- Familiarity with command-line tools
- Programming experience (Java, Python, or Node.js recommended)
- Understanding of basic networking concepts

- **Apache Kafka 3.x** - Core streaming platform
- **Docker and Docker Compose** - Container orchestration
- **Programming Languages:** Java 11+, Python 3.8+, Node.js 16+
- **UI Tools:** Kafka UI, Conduktor, Offset Explorer
- **Monitoring:** Prometheus, Grafana
- **Schema Registry** - Schema management
- **Kafka Connect** - Data integration
