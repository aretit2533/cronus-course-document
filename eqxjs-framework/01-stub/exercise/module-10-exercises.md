# Module 10 Exercises: Advanced Patterns

## Overview

These exercises focus on advanced enterprise patterns and integration scenarios.

## Exercises

1. **Policy-Driven Validation**
   - Centralize validation rules and apply them via decorators.
   - Add reusable validation helpers.

2. **Resilience Patterns**
   - Add circuit breaker or bulkhead patterns to outbound calls.
   - Validate fallback behavior under failure.

3. **Cross-Cutting Interceptors**
   - Implement a global interceptor for masking and response envelopes.
   - Ensure legacy compatibility where required.

4. **Enterprise Integration**
   - Add a new integration with external service mocks.
   - Provide configuration for multiple environments.

## Deliverables

- Advanced patterns implemented in a sample feature.
- Clear documentation of decisions and tradeoffs.
