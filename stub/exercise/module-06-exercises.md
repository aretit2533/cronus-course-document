# Module 6 Exercises: Logging and Monitoring Systems

## Exercise 6.1: Standard Log Schema

**Goal:** Define a structured log schema for your service.

**Tasks**

1. Define required fields.
2. Define optional fields for errors and dependencies.

**Deliverable**

- A JSON schema-like description + 2 example log entries.

---

## Exercise 6.2: Masking Policy

**Goal:** Create a masking policy.

**Tasks**

1. List sensitive keys.
2. Define masking behavior for each (redact/partial).

**Deliverable**

- Masking table + before/after examples.

---

## Exercise 6.3: Metrics and Alerts

**Goal:** Define operational metrics and alerts.

**Tasks**

1. Define 5 key metrics (rate/errors/latency/dependency/lag).
2. Define 3 alert rules with thresholds and durations.

**Deliverable**

- Metrics list + alert definitions.
